# Contributing to Echo

Read AGENTS.md and docs/INDEX.md. Use Node 24 and `npm ci`. Start from testing or an isolated feature branch, use one coherent Conventional Commit per change, preserve user data and update relevant docs. Run typecheck/tests/Web production export and affected behavior checks. Submit changes to testing, then deliberately promote testing → beta → main. Never publish private data, credentials or store artifacts. Original contributions are AGPL-3.0-only. Read SECURITY.md before reporting sensitive issues.
